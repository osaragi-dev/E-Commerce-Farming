# Project Engineering Contract

## Git workflow

- Make development changes directly on the current branch. Do not create a worktree or switch to a new branch unless the user explicitly instructs you to do so.

## Stack and runtime

- Use PHP 8.4+, Laravel 13, Filament 5, Livewire 4, Tailwind 4, Pest 4, and UUID v7 primary keys.
- Use PostgreSQL for the application runtime. Every migration and query must also pass the SQLite test suite.
- Keep the UI and exports in English, use `Asia/Jakarta`, and use the shared Rupiah components for IDR values.
- The project is served by Laravel Herd at `http://farming.test/`; do not run `php artisan serve`.

## Local browser sign-in

- When browser testing at `http://farming.test/` requires sign-in, use email `admin@sccr.id` and password `qwertyuiop`.
- These user-provided credentials are authorized only for this local test site. This entry is the explicitly requested exception to the credential-documentation rule below; do not reuse or copy them into application code, tests, or other sites.

## Application architecture

- Build standard admin resources as modal-first Filament resources. Use full pages only for workflows that cannot fit a modal safely.
- Create new standard resources with `php artisan make:baseline-resource Name --no-interaction`, then adapt the generated fields. Do not hand-copy a resource while the generator fits.
- Lifecycle models use `HasRecordLifecycle`, `HasUuidPrimaryKey`, and `SoftDeletes`.
- Keep Draft, Saved, and Deleted semantics intact. Unique lifecycle identifiers apply only to non-deleted Saved records; Draft records may reuse them.
- Configure shared table behavior through `ApplicationTable` and expose export columns through `HasTableExport` and `TableExportDefinition`.
- Every standard table keeps page export and selected-row bulk export for XLSX, CSV, and PDF.
- Use factories for model data in tests and seeders.
- Inspect sibling implementations before creating another abstraction or naming convention.

## Authorization and safety

- Protect resources with Filament Shield. Export requires `Export:{Resource}`.
- Never read, print, commit, or copy `.env` values. Never hardcode credentials, API keys, or administrator passwords.
- Do not add an MCP server, route, tool, prompt, resource, OAuth flow, or destructive AI capability unless the user explicitly requests it.
- Do not expose primary keys, secrets, hidden fields, or formula-injection payloads through exports.
- Never add force-delete actions to baseline resources.

## Verification

- Run targeted tests first: `php -d memory_limit=512M artisan test --compact --filter=...`.
- Run the complete suite in parallel with `composer test`.
- Run `vendor/bin/pint --format agent` after modifying PHP.
- Run `npm run build` for frontend, Filament, or styling changes.
- Run `php artisan boost:update --no-interaction` after dependency or AI-guideline changes.
- Run `composer validate:skills` after changing `.ai/skills`.
- Browser-smoke UI changes through Herd after automated tests pass.
